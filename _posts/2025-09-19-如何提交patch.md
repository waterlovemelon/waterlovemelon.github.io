## 1 常用的流程

下面以 network-manager 项目为例子说明

- 从 gerrit 上下载项目并切换到 uos 分支

```shell
$ git clone "http://gerrit.uniontech.com/base/network-manager"
$ cd network-manager
```

- 根据项目的情况, 初始化 quilt 环境

```shell
$ export QUILT_PATCHES=debian/patches
一般来说debian系linux发行版位置为debian/patches, 有时候你需要结合实际调整
```

- 加载已经存在的 patch

```shell
$ quilt push -a
```

- 增加一个新 patch, patch 命名参考项目规范, 这里为 test

```shell
$ quilt new test.patch
   Patch debian/patches/test.patch is now on top
$ cat debian/patches/series
   test.patch
   Do-not-manage-Docker-bridge-interfaces.patch
   supplicant-fix-setting-pmf-when-the-supplicant-doesn-t-ad.patch
   Force-online-state-with-unmanaged-devices.patch
   Don-t-setup-Sleep-Monitor-if-not-booted-with-systemd.patch
   Don-t-make-NetworkManager-D-Bus-activatable.patch
   fix-SpecificObject-not-updated-after-WiFi-roaming.patch
```

- 把需要补丁的文件加入到 patch 中, 例如 TODO -需要先 add 再修改文件,add 相当于记录一下对应文件当前的快照-

```shell
$ quilt add TODO
   File TODO added to patch debian/patches/test.patch
```

- 修改 TODO 文件

```shell
$ echo test >> TODO
```

- 更新 patch 文件

```shell
$ quilt refresh
   Refreshed patch debian/patches/test.patch
```

- 查看 patch 文件

```shell
$ cat debian/patches/test.patch
   Index: network-manager/TODO
   ===================================================================
   --- network-manager.orig/TODO
   +++ network-manager/TODO
   @@ -291,3 +291,4 @@ Consequently the same behavior should be
    available.  This behavior should be suspended when special connections like
    Internet Connection Sharing ones are started, where clearly the priorities
    are different (ie, for Mobile Hotspot 3G > WiFi).
   +test
```

- （可选）清除加载的 patch

```shell
$ quilt pop -a
```

- 这里我们完成了 patch, 接下来填写 changelog

```shell
$ dch -i
   自行修改版本号, 邮件, 内容. 版本号根据规范来 一般是 最后一个数字+dde
   改好后保存即可
```

- 以上完成了整个流程, 按规范提交 gerrit 就可以了

## 2 其他命令

quilt files - 查看当前 add 的文件

quilt top - 查看当前工作 patch

quilt remove - 取消关联文件，是 add 相反的操作

quilt pop - 丢弃当前 patch，并切换到上一个 patch

quilt push - 应用当前 patch，并切换到下一个 patch

quilt delete - 删除当前 patch

quilt series - 查看当前 patch 列表

quilt apply - 应用指定 patch

quilt unapply - 取消应用指定 patch

quilt import - 导入一个 patch 文件

quilt export - 导出一个 patch 文件

quilt diff - 查看当前 patch 的 diff

quilt new - 创建一个新的 patch

quilt refresh - 更新当前 patch

quilt add - 添加文件到当前 patch
删除文件方法：先 quilt add 该文件，然后直接在文管删除文件。

重命令文件方法：先删，再新建。
